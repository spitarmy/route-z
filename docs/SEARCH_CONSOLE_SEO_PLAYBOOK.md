## 3. Search Console 自動改善ループ（月次運用）

### (1) 分析サイクル
- 毎月「**直近28日間**」および「**過去3か月間**」の2期間を抽出し比較。
- 必ず **Clicks / Impressions / CTR / Position** を全取得。

### (2) クエリ分離
1. **Brand Query**：`Route Z`、`ルートゼット`、`route z`、`bar z` など
2. **Non-Brand Query**：`祇園 バー`、`祇園 アフターバー`、`祇園 バー 隠れ家` など

### (3) 改善優先順位ルール
- **【優先度 A】表示回数 10以上 ＆ 順位 4〜15位 ＆ クリック 0〜少数**
  - **最優先改善**：上位表示されているのにクリックされていない最重要ターゲット。
  - **施策**：検索結果一覧でのクリック率を高めるため、title・meta descriptionの訴求見直し、見出し（H2）の検索意図整合。
- **【優先度 B】順位 11〜30位**
  - **施策**：コンテンツ加筆、関連トピック追加、TOPおよび親ページからの内部リンク強化。
- **【優先度 C】順位 1〜5位 ＆ CTRが低い**
  - **施策**：titleのクリック動機（価格明朗・八坂神社すぐ・一人飲み歓迎など具体ベネフィット）強化。
- **【優先度 D】表示回数 0〜数回**
  - **施策**：即座に大量リライトせず、クエリの成長を静観する。
